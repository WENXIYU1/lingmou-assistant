# 头部基准引导与坐标排查

2026-09-22；需求：CAL-01/CAL-02、SAFE-01、UI-01、DATA-01。用户已批准。仅本地修改，未合并发布。

## 实现

- 新增 head_reference.py：有界90帧、最近2秒姿态缓存。至少18帧及1.2秒有效稳定片段后可明确确认；无效帧、时间断层清空缓存，过期数据不能确认。建立基准的稳定性容差是实验值，需真人评估。
- 侧栏显示黄参考/蓝当前轮廓及眼线倾斜，不显示原始画面。坐标明确为摄像头非镜像坐标；横向提示指图中蓝轮廓的移动方向。距离和倾斜使用尺度/角度代理，不宣称厘米距离或完整三维姿态估计。
- 新校准要求先确认舒适基准。偏离现有容差即暂停当前点；回到范围不自动恢复，继续按钮检查姿态和环境后重采当前点，保留已完成点。
- 重建基准清除当前映射/验证状态。相机关闭、切人、环境改变均失效。有效档案已有 mapping.head 字段存储所确认的基准，加载后展示并要求独立验证；档案格式不变。失败会话的基准不单独持久化。
- 没有更改模型、视线特征、10%/18%验证门槛或系统控制锁定，没有加入网络请求。头部位置稳定不保证视线估计准确。

## 坐标审查

目标和虚拟光标均使用归一化坐标乘当前 Tk Canvas 宽高；验证按同一画布宽高计算欧氏距离/对角线。窗口屏幕原点和Tk缩放只用于环境失效检查，不混入局部目标坐标。关键点在摄像头实际宽高内转换，双眼局部眼角轴均按33→133和362→263定义，当前代码没有仅对其中一条链路施加镜像。

未发现足以解释真人整体左上偏移的确定坐标错误。此为代码审查及合成测试结论，不代表实际摄像头、驱动或所有DPI配置已验收。
