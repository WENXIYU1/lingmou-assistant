## 本机打开

双击根目录 `启动新算法实验.cmd`，或在项目目录执行：

```powershell
.\.venv\Scripts\python.exe -m apps.desktop --gaze-experiment
```

标题必须显示“新算法实验”。关闭其他占用摄像头的程序，戴日常眼镜，保持与旧算法对照时相同的光照和坐姿；默认请求1280×720，实际尺寸仍以采集质量审计为准。手动确认开启摄像头，稳定后确认舒适头部基准，再开始五点校准。训练合格后依次进行三点选型、另一轮全新三点最终验收，之后明确开始画布试用。可按Esc暂停。不要在采样中移动或缩放窗口。

本轮仅会话内存；实验入口不加载或保存个人档案，原算法入口仍为 `--camera`。每轮实验都重新校准。失败后点击“查看定位诊断”，保留具体原因和逐点验证误差，避免反复无目的重做。原始图像不保存或上传。

## 实际处理

MediaPipe负责单人关键点、双眼质量和舒适姿态范围；官方头姿模型从本地人脸裁剪估计yaw/pitch/roll；官方视线模型输入双眼BGR裁剪与这些角度。单位三维视线向量的X/Y再经个人五点映射变成画布位置。眼部、人脸裁剪比例为实验值，当前使用MediaPipe框定人脸，和官方人脸检测器裁剪不完全相同，须真人评估这种差异。

新模型比较普通仿射及点内波动惩罚两种映射；五点只作训练，第一组三点只选型，下一组三点才用于最终验收。屏幕误差训练门槛10%、独立验收中位10%及最大18%保持原值。新模型训练波动门控见本文最新章节。九点和重复中心尚未加入，先建立五点可运行对照。
