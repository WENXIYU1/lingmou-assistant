# 混合映射候选与两阶段独立验收

关联需求：CAL-01、CAL-02、EYE-01、UI-01、SAFE-01、DATA-01。

## 已实现范围

- 五点训练同时构建双眼平均基线，以及横向双眼平均、纵向左眼的100、150、200毫秒因果中位数候选。
- 每个候选只使用五点训练数据拟合，并须满足五个训练点逐点中位误差不超过画布对角线10%；不可靠候选记录原因并淘汰。
- 第一组三点分别评估仍可用的候选，按中位误差、最大误差顺序选择；该结果明确标记为“选型数据”，不产生通过结论。
- 选择后清空采样组，再采集第二组全新三点；只有该组同时满足中位≤10%、最大≤18%，才能进入画布试用。
- 混合候选的训练、两轮评估和画布试用共用同一因果处理；只读取当前及过去样本。每个点位、暂停、丢失跟踪或时间间隔异常后重新建立历史。
- 映射档案新增特征模式与时间窗口字段，映射版本为`hybrid-candidate-two-check-v3`；旧档案拒绝加载并提示重新校准。

## 操作变化

新用户完整校准共11点：五点训练、三点选型、三点最终验收。界面分别显示“候选选型（三点，不计最终通过）”和“最终独立验收（全新三点）”。加载由本版本保存的档案仍执行一组三点快速验证，不再次选型。

定位诊断会显示各候选训练最差点误差、被淘汰原因、第一组三点的候选中位/最大误差及最终选择。报告仅驻留会话内存；不保存原始画面或上传特征。

## 验证与限制

- 自动单元测试覆盖候选窗口版本、因果性、间隔复位、训练—选型—最终验收状态分离、加载档案快速验证和旧版本档案拒绝。
- 模拟界面覆盖11点流程、安全锁定、试用和保存；不访问真实摄像头。
- 画布提示区布局检查确认阶段文字变化不改变画布尺寸。
- 真人戴镜11点校准、最终误差、100/150/200毫秒候选选择结果、主观迟滞和长期漂移：未验证。
