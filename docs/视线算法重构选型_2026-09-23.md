# 视线算法重构选型（2026-09-23）

关联 CAL-01/CAL-02/EYE-01/SAFE-01/DATA-01。本文是实验选型，不是新算法已实现或真人通过验收的声明。

## 当前判断

最近一次戴镜五点训练中，所有候选最差点中位误差均超过实验门槛10%（双眼14.99%，混合100/150/200毫秒分别10.45%/12.98%/13.45%）。上下点预测明显向画布中心收缩；中线短测虽有上下信号，点内波动与上下差接近。现有虹膜/眼睑几何特征加仿射映射不宜继续靠放宽门槛或延长平滑窗口宣称解决。头部特征目前仅作漂移门控，未作真正视线方向估计。眼镜反光和头姿可能影响结果，但这些数值不能单独证明原因。

[MediaPipe Iris](https://research.google/blog/mediapipe-iris-real-time-iris-tracking-depth-estimation/)明确不直接推断注视位置。因此需要增加独立的视线方向模型作对照，而非仅重新拟合当前特征。

## 候选比较

| 方案 | 取舍 | 本轮结论 |
| --- | --- | --- |
| 当前几何特征 + 仿射 | 轻量、已有安全流程；真人戴镜训练未达标 | 保留基线，不再直接作为精度已解决方案 |
| [OpenVINO gaze-estimation-adas-0002](https://github.com/openvinotoolkit/open_model_zoo/blob/master/models/intel/gaze-estimation-adas-0002/README.md) | 本地输入双眼60×60裁剪与真实头部 yaw/pitch/roll，输出三维视线方向；约188万参数、0.139 GFLOPs；需补眼部裁剪与头姿估计，并做个人屏幕标定 | 首选**实验基线**，不是已证明最准确 |
| [L2CS-Net](https://github.com/Ahmednull/L2CS-Net) | 可直接估计视线角度；ResNet50较重，预训练权重的上游许可需逐项核查 | 第二候选，暂不打包 |
| [ETH-XGaze](https://github.com/xucong-zhang/ETH-XGaze) | 研究价值高；公开代码非商业许可且工程依赖较旧 | 不作为首个安装包方案 |

OpenVINO官方报告的约6.95°是其内部留出人员的角误差，不是本机戴镜用户的屏幕像素误差，也不能保证眼镜适配。[模型元数据](https://github.com/openvinotoolkit/open_model_zoo/blob/master/models/intel/gaze-estimation-adas-0002/model.yml)提供权重来源与校验值。后续实施已完成本机模型下载、SHA384核验及实验画布接入，详见[新算法实验使用与验收](新算法实验使用与验收.md)；真人精度尚未验收，未采集或上传用户原图。

## 下一阶段的有界实现和验收

1. 在隔离的本地实验模块接入OpenVINO，缺少模型时正常降级，不影响现有安全练习和键鼠。眼睛裁剪仅留内存；头部输入必须是实际角度，不可把当前五维头部代理值冒充 yaw/pitch/roll。
2. 在同一摄像头、分辨率、眼镜、光照与坐姿条件下采集个人屏幕标定；增加重复中心和足够覆盖全屏的点位，分别拟合当前映射与三维视线方向到屏幕坐标的映射。候选只用训练/选型数据确定。
3. 用全新保留点作最终独立验收，记录逐点X/Y误差、总体中位/最大误差、有效帧率、头姿范围和目标选择成功率；同一份最终数据不得反复选型。眼镜反光、头姿变化、边角位置分别测。真人未通过前系统级眼控点击继续锁定。
4. 若OpenVINO仍不达标，再检查特征/裁剪和真头姿质量，比较L2CS或个体轻量回归；是否换模型由同条件真人独立结果决定，不靠论文指标或合成测试推定。

实施状态：`gaze_experiment.py`保留纯输入输出接口，`gaze_pipeline.py`按官方清单SHA384校验并加载头姿和视线模型，在摄像头子进程运行；`--gaze-experiment`提供安全画布，沿用五点训练与两轮三点检查。早期SHA256显式加载适配器`openvino_gaze.py`保留作独立接口测试，实际实验入口使用清单加载器。权重、运行时和真实模型合成输入测试已完成；真人戴镜精度、九点方案和正式安装包未完成。
