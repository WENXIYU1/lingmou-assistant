# 第一步优化报告

日期：2026-09-22。状态：第一步模拟练习版本完成本地自动测试；真实眼控与完整适配未验收。

## 本轮范围

SAFE-01、EYE-01、EXEC-01基础与CAL-01前置安全入口；REPO-01私有库建立。核心为新的模块化练习原型，不原地修改参考源码。

## 基线发现

原版使用固定14倍增益、单轴超死区即更新双轴、短眨触发双击、闭嘴自动启用、系统安全保护关闭及异常吞掉。缺少face_landmarker.task，初始环境无OpenCV、MediaPipe及CustomTkinter，未启动原摄像头循环，未取得原版真人精度或延迟基线。

## 实现边界

新版分为config、vision输入协议、calibration状态入口、interaction、executor、storage和ui。只输出画布及模拟事件，无系统注入后门；没有声称完整校准通过。参数仅供模拟试用，不是最优人体参数。

主流程与异常路径自动测试覆盖启动暂停、丢失与恢复、时间戳、短眨、持续动作、防重复、中心重置、双轴控制、配置验证与保留备份。

## 实际验证记录

本地隔离环境Python 3.12，UI依赖固定为CustomTkinter 5.2.2、darkdetect 0.8.0、packaging 24.2。

| 命令（项目根目录） | 结果 |
|---|---|
| `.venv/Scripts/python.exe -m unittest discover -s tests -v` | 27项通过；纯模拟输入，无设备或云调用 |
| `.venv/Scripts/python.exe -m apps.desktop --check` | 正确报告仅模拟、系统控制关闭、校准未实现、视觉依赖和原模型缺失 |
| `.venv/Scripts/python.exe -m scripts.ui_smoke` | 隐藏窗口组件测试通过，包括暂停、恢复信号不自动启用和适配锁定；不等于视觉验收 |
| `.venv/Scripts/python.exe -m scripts.baseline_replay` | 同一合成位移下，旧公式纵轴联动0.00028，新版纵轴0；只证明独立死区逻辑，不是眼控精度提升数据 |
| `.venv/Scripts/python.exe -m compileall -q apps tests scripts` | 编译检查通过 |
| `.venv/Scripts/python.exe -m pip check` | 无依赖冲突 |
