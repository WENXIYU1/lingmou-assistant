# MobileGaze独立短测（2026-09-23）

需求：EYE-01、CAL-01、SAFE-01、DATA-01。用户批准L2CS系整脸路线对照；本轮只做短测，不替换主算法、不提供屏幕映射、系统鼠标或个人档案保存。

## 使用

关闭旧摄像头窗口，双击根目录“启动整脸方向短测.cmd”。窗口标题必须包含MobileGaze。明确开启摄像头、确认舒适头部基准，点击“开始头动补偿对照”。前5组始终看中心圆点，依次保持舒适中心、头部向本人左侧轻移、右侧轻移、向上轻移、向下轻移；移动整个头部但不要明显转头，不必达到边界。随后按中、左、中、右、中、上、中、下、中完成9组全新评估。每组准备1秒并收集至少24帧/2秒，全程通常约50～70秒。Esc暂停；跟踪中断或姿态超范围后须明确继续。报告不表示定位通过，不自动选型/纠偏。眼镜为正常条件，无需摘镜。把完整报告复制给开发者分析，默认不落盘。

## 来源与差异

- 权重：[作者发布的resnet18_gaze.onnx](https://github.com/yakhyo/gaze-estimation/releases/download/weights/resnet18_gaze.onnx)，45066134字节。
- 发布API SHA256：`404fec1efd07ff49f981e47f461c20c2627119e465ec441bbd1c067d3f16e657`，本机下载已核对。
- [MobileGaze仓库](https://github.com/yakhyo/gaze-estimation)：L2CS系ResNet18，Gaze360训练，不是原版L2CS-Net权重。
- 复用OpenVINO 2026.4.0 CPU运行新ONNX，不再调用旧OMZ视线或头姿模型。输入RGB 448×448、ImageNet归一化；命名yaw/pitch各90个logits，softmax期望解码为角度。
- 人脸框暂用MediaPipe关键点包围框，而作者采用RetinaFace；不镜像相机输入。检测/裁剪差异仍可能影响精度，不能声称完整复现。
- 运行时仅本地加载校验成功的权重；下载仅显式运行`python -m scripts.setup_mobile_gaze`。无摄像头原图保存上传，权重位于Git忽略目录。

## 九点漂移对照（2026-09-23）

需求EYE-01/UI-01/DATA-01/SAFE-01。本轮不换模型、不拟合映射、不调整安全门槛。保留旧七点类作回归，新MobileGaze界面入口使用九点类。FeatureFrame新增可选face_crop四标量：实际输入裁剪框中心X/Y、宽/高，分别按图像宽高归一化；不保存图像或关键点数组。头部五标量为几何代理，不是模型姿态角。每点报告头部与裁剪框中位、P90-P10及中心复测相对首次的绝对差（尺度/框宽高差不是比例变化）。缺失裁剪信息明确标注，不填零。

角度对照仅选取过去300毫秒内至少3帧的时间点，原始和处理后使用相同时间点；每点独立历史，暂停/重采丢弃当前未完成片段。窗口跨度不称为真人延迟，不由配对结果自动选择算法。窗口由原200毫秒改为300毫秒，是因为同帧双路推理实测导致200毫秒内不足3帧；保留原始角度对照以显式展示稳定与延迟取舍。头部/裁剪数值按本点全部有效采样统计，与配对角度数量可能不同；共同变化不能单独证明因果。

本轮Windows本地139项自动测试、界面模拟、真实权重合成输入测试均通过，无摄像头访问。头动补偿版真人戴镜测试未运行；不将用户此前粘贴的会话结果写入仓库。方向可分离不等于可精确控制屏幕。

## 稳定人脸坐标影子对照（2026-09-23）

同一摄像头帧先按原MediaPipe人脸包围框推理，再使用双眼外眼角把画面平移、等比缩放和旋转到固定会话参考，按参考人脸框进行第二次推理。用户确认/重建舒适头部基准后重置稳定参考；参考只在采集进程内存中。该变换不校正三维侧转或俯仰，也不声称等同作者的RetinaFace预处理。

报告分别列出原始裁剪和稳定裁剪的原始角度、300毫秒因果中位数，并汇总左右/上下分离、中心复测最大绝对偏移及各点P90-P10中位数。两路已改为一次批量为2的本地推理；本机合成输入纯推理20次均值83.7毫秒，不含摄像头读取和人脸检测，不能当成端到端帧率或真人延迟。采样间隔、12秒超时和安全暂停门槛不放宽。稳定裁剪失败只令影子数据缺失，不会把原始模型结果改成无效。影子结果不参与动作、映射或自动选择。

真人同帧结果显示稳定裁剪虽增强横向分离，但纵向分离下降、中心纵向漂移增加，因此该路线已退出实时入口。代码仅保留研究回归；运行时恢复单路原始MobileGaze推理，不再计算稳定裁剪影子结果。上述83.7毫秒是历史batch=2测量，不代表当前单路性能。

## 头动泄漏补偿对照（2026-09-23）

前5组只允许注视同一中心目标，以五组头部中心X/Y中位数和原始模型角度中位数拟合带固定岭惩罚的二维线性串扰模型。只使用头部中心X/Y两个变量；尺度、倾斜和侧转不进入模型，避免五组数据拟合过多参数。横向和纵向头位跨度都必须达到画面归一化0.012，否则明确拒绝生成补偿。

补偿只减去相对舒适头部基准的预测角度变化，不改变基准角度。后9组方向数据完全不参与拟合或调参，同时报告原始、原始因果中位数、头动补偿、头动补偿因果中位数。训练内RMS只描述拟合，不作为有效证据；是否改善只比较后9组的方向分离、中心复测漂移和P90-P10波动。所有系数和样本仅驻留会话内存，不写档案，不用于控制。

## 短测计时修正（2026-09-23）

需求：EYE-01、SAFE-01、UI-01。开始或重采时，早于本点开始时间采集、稍后才送达的有效帧不进入采样，也不重置计时；避免将正常推理延迟误报为时间异常。收到本点新帧后，时间倒退或重复仍暂停。无效跟踪、头部偏离、超过0.25秒的采样间隔仍保留暂停保护；超过12秒的本点采样超时单独提示。适用于上下短测及七点方向短测，不改变定位算法或验收门槛。

本轮130项自动测试及无摄像头界面模拟通过；修正后的真人摄像头短测尚未验证。此前用户已进行真人尝试，但不能据此认定本轮修正已通过真机验收。人脸裁剪不合格等其他中断原因不由此修正解决。
