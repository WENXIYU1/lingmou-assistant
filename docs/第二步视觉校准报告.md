# 第二步：视觉接入与个人校准候选版

日期：2026-09-22。分支：`codex/vision-calibration`。需求：CAL-01、CAL-02、EYE-01，回归SAFE-01。

状态：代码与模拟流程已完成；真实摄像头和真人校准未运行，不能标为完全验收，不合并main。默认不打开摄像头，系统级输出仍禁止。

## 实现内容

1. 官方固定模型来源、校验清单和显式下载脚本；模型权重不入Git。
2. 用户主动确认后才启动独立采集进程；最新帧队列限制为1，丢失标记独立传递；停止后丢弃晚到帧，退出超时强制结束本程序的采集进程。
3. 双眼虹膜环估计与眼角局部坐标；闭眼、越界、单眼质量不足、多脸、明显侧转等帧不进入采样。相对坐标不能消除所有头部影响，另检查姿态变化。
4. 五点采样、稳健片段聚合、仿射拟合、秩和尺度检查；三点未参与拟合的独立验证；不裁剪验证预测以掩盖误差。
5. 画布停留试用与人工确认保存；加载档案后重新验证。调整增益、死区、平滑或停留参数后重新验证/试用。
6. 用户别名隔离，环境包括摄像头编号/设备标记、实际分辨率、屏幕与窗口画布几何、缩放和模型版本；窗口移动也会使映射失效。

## 参数及限制

采样：每点至少18个有效样本、连续片段至少1.2秒，目标切换后等待1秒，单点20秒超时可重试。门槛均为待真人验证的初始参数，不是医学指标。

独立验证：按画布对角线归一化，中位误差不大于0.10且最大误差不大于0.18，保存中位/P90/最大误差及样本数和策略版本。上述相对宽松阈值只用于大目标练习，不适用于系统级小按钮或声称高精度。

当前要求双眼、单人、较稳定正面姿态；不支持单眼映射自动切换。未提供原始画面预览，只有质量提示。质量下降会暂停试用，包括闭眼可能造成的频繁暂停；真人验证需记录这一负担，再审批优化，不静默降低安全约束。

摄像头编号不等于永久设备身份，提供设备标记并在每次加载后独立验证；更换设备应新建或重校准。不同窗口位置也不能直接沿用档案。当前不是跨显示器通用眼控方案。

## 需要用户完成的人工验收

1. 运行`.venv/Scripts/python.exe -m apps.desktop --camera`，确认摄像头尚未开启、系统控制锁定。
2. 输入本人别名和设备标记，点击开启并确认；检查权限失败/占用时的提示是否清楚。
3. 双眼可见且质量合格后开始校准，依次注视5个目标，进入3点独立验证；记录失败位置与原因。
4. 验证通过后明确开始画布试用，停留命中3个目标；若漂移、追不上或过于灵敏，记录感受并暂停，不尝试系统点击。
5. 试用期间闭眼、转头、离开画面，确认不会误触，恢复后需明确继续；记录正常眨眼导致暂停的频率。
6. 确认保存后重新启动并加载同名档案，必须要求快速验证。换别名或改变窗口/设备环境时，不沿用通过状态。
7. 关闭摄像头/退出，确认摄像头指示灯熄灭。若不能及时释放，报告设备型号和过程。

记录真实结果后决定是否合并。模拟全部通过不能替代这些步骤；任何精度改善比例都需要同条件实测。
