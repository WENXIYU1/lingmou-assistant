# 纵向特征对照与训练检查

2026-09-22。已获批准；需求CAL-01/EYE-01/UI-01/DATA-01。本地实现，未推送、合并或发布。

## 变更与边界

- 保留原虹膜眼角坐标和实际控制映射不变。候选纵向坐标为虹膜中心相对上眼睑的位置，除以上下眼睑沿眼角轴法线方向的间距；横向仍为原坐标。闭眼沿用原质量拒绝；候选不在[0,1]时标为缺失，不裁剪，也不影响原特征判断。
- 新增左/右/双眼眼睑候选，与原三种共六种影子映射。全部仅用五点训练，同一独立验证只评测不再拟合。未自动选型，不支持将候选直接写入档案或控制系统。
- 对每个候选报告五点纵向特征中位、P90-P10波动和下排减上排差值；即使拟合退化，也保留可获得的输入信号统计。差值与波动仅帮助判断输入可区分性，不直接诊断人体或宣称因果。
- training-point-median-v1：原映射五个训练点中任一点的全体有效帧中位误差>10%画布对角线即停止，清除当前映射，不进入三点验证，保留训练诊断。是新增实验质量门槛，不是已验证准确率，也不修改原独立验证10%/18%门槛。
- 训练停止时画布显示具体原因并引导查看诊断；旧档案快速验证没有当时训练帧，不补造训练检查结果，仍须通过原独立验证。
- 数据仅在会话内存，没有新增图像/特征文件写入或网络请求，旧档案格式不变。
