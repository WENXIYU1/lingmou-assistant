# 校准失效与映射稳定性修复

2026-09-22；CAL-01/CAL-02/EYE-01/UI-01；用户已批准继续实施。修改仅本地，未推送、合并或发布。

## 确认的问题及修复

无摄像头的可见窗口测试复现：将短提示换为长提示，画布从1186×916变为1186×710。原程序严格比对画布尺寸，提示文本自身改变布局即可触发invalidate，随后session被清空且诊断丢失。此路径确定存在，不能据此断言用户每次失败都由此造成。

固定状态区高度，长提示不再改变画布。复测同一长短提示画布均为1186×793。超长信息可在可滚动诊断窗口阅读。用户主动缩放/移动窗口仍按原规则失效。

失效前保存最近一次同用户文本报告（阶段、错误、失效原因、已完成点数、候选统计及验证指标）。仅保留一份内存文本，后续无会话的关闭事件不覆盖它，切换用户清除。诊断窗口显示当前和上一轮，已失效报告不恢复任何控制资格；退出程序不持久化。

## 映射修正

原拟合只使用五个中位点，即使点内波动很大也不影响最小二乘系数。新版在标准化特征上加入各点内残差二阶矩的惩罚：求解(DᵀD+N)B=DᵀT，N仅来自训练保留样本、每个目标等权，截距不惩罚。这样限制噪声方向的输出放大，不增加运行时滤波延迟。可能引入向中心收缩的偏差，故训练检查与独立验证均保持原门槛。

映射版本改为affine-within-point-penalty-v2；旧档案明确不兼容，需要重新校准，不静默沿用。旧v1只在诊断中对照训练/验证误差，不参与候选自动选择。未使用用户验证结果反向训练或调参。
