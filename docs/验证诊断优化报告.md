# 验证诊断与采样引导优化

日期：2026-09-22。范围：CAL-01、UI-01、DATA-01；用户已批准。

## 变更

- 验证失败后在画布显示总体中位和最大误差及门槛，逐点显示中位/最大误差、预测中位位置相对目标的像素偏移、围绕该中位位置的距离P90（波动）。标明最大单帧偏差来自哪个验证点。
- 目标出现后显示原有1秒准备时间的倒计时；采样期间显示连续有效片段秒数和帧数。仍需至少1.2秒和18帧，异常片段清零，主动暂停不自动恢复。
- 诊断是会话内统计，不写新增诊断文件，不保存原始画面，不上传；档案格式、拟合算法、验证门槛10%/18%、系统控制锁定均未改变。
- 偏移和波动仅用于排查，不能据此确定光照、姿态或模型等具体原因。此轮没有实现姿态补偿、换模型或自动调参。

## 验证

环境：本机Windows，项目Python 3.12虚拟环境。数据：合成特征、模拟摄像头。

- `.venv/Scripts/python.exe -m unittest discover -s tests`：62项通过。新增覆盖固定偏移与零波动、单个异常帧仍触发最大误差门槛、波动与偏移区分、倒计时/暂停。
