# 上下短测与稳定处理对照

关联 CAL-01/EYE-01/UI-01/SAFE-01/DATA-01。此实验用于定位戴镜时纵向特征的可区分性，不代替校准或独立验证。

## 使用

1. 开启摄像头，戴日常眼镜，以舒适姿态保持约1.2秒。
2. 点击“开始上下短测（无需五点校准）”。旧校准失效，系统控制保持锁定。
3. 沿屏幕中线看上、中、下、中四个圆点。每点准备1秒，采样至少2秒且至少24帧。无需点击目标。
4. 跟踪中断或头部偏离时，调整后点击“继续 / 重采当前点”；Esc可随时暂停。
5. 点击“查看上下短测报告”，将文字复制给开发者分析。不必继续反复做五点校准。

## 解释边界

原始值与过去0.20秒中位数使用相同时间点；每点至少3帧预热，报告每点中位、P90-P10、上下差、两次中点差。分眼特征缺失或配对样本不足时不可比较。波动下降不等于定位精度改善；没有真人响应延迟测量，不声称“无延迟”。暂不将中位数处理接入控制，也不根据结果自动挑选眼睛。

只保留标量特征，无原始图像、文件保存或网络上传。每点最多240条，最多四点；切换用户、环境或开始其他校准后清除。报告窗口是静态文本，关闭窗口可移除显示。

真人戴镜效果和真实响应延迟仍待用户测试；合成数据只能检查流程和安全边界。
