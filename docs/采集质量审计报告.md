# 采集质量审计与拟合失败细化

2026-09-22；CAL-01/EYE-01/UI-01/DATA-01；已批准。本地修改，未合并、发布或推送。

## 内容

- 新增“采集质量审计（无需校准）”实时只读窗口。打开时暂停采样/控制，摄像头仍由用户手动开启。每500ms刷新最近10秒、最多300个界面接收结果统计。
- 实际图像尺寸来自frame.shape；显示结果到达率、有效结果率、有效占比、最近结果距今时间、接收时帧龄、无效原因计数。有效要求原特征有效且帧龄0–0.25秒。
- 眼部宽度为有效帧左右眼角距离的像素中位数，不是虹膜直径；没有有效测量时显示不可用，不把缺失当0。
- 速率以界面接收时间计算，少于1秒不估计；区间首样本不计入速率分子。包含推理和队列影响，被覆盖结果未计入，因此不能称为摄像头硬件帧率、推理吞吐或完整采集有效率。停止后最近结果年龄持续增加，超过10秒无新数据则提示无最近数据。
- 每点拟合记录输入、保留、剔除帧数及保留样本X/Y标准差；异常分别报告“保留少于18”与“标准差超过0.035”，不更改原有过滤逻辑。多点过滤失败均保留诊断。
- 已拟合候选报告每个输入特征增加0.001时画布X/Y像素响应（含用户增益）。这是仿射系数的解析响应，不是相机噪声实测或准确率。
- 原始图像不显示、不保存、不上传；新增统计仅会话内存，旧档案格式不变。没有自动启用眼睑候选或改变控制/验证门槛。
