# 戴镜输入排查

2026-09-22；CAL-02/EYE-01/UI-01/DATA-01，用户已批准。本轮未启用真实摄像头，未推送/合并/发布。

## 已实现

- 默认戴日常眼镜，也可选未戴眼镜；不收集度数。状态写入有效档案的environment字段，切换状态清除本次校准；换镜提供明确的清除入口。旧档案缺少此字段会因环境不匹配被拒绝，不猜测旧状态，不自动覆盖。
- 请求640×480或1280×720，切换时关闭采集并失效校准，用户手动重开；审计同时展示请求与实际尺寸，返回不一致明确提示。没有改变模型输入预处理，也不承诺更高清必然更准。
- 单独确认后开启本地眼部裁剪预览：上方原裁剪，下方关键点叠加；绿色虹膜点、黄色眼角/眼睑点。非镜像，显示放大不增加采集细节，不自动判断反光或遮挡。
- 子进程只在预览授权事件启用时构造图像；裁剪最多600×360 RGB像素，通过原有容量1的本地队列传递。无单人关键点或无效坐标不生成预览，不回退显示整张脸。
- 界面只显示本次开启后且帧龄≤0.25秒的图像；超时/无可用裁剪清空。关闭预览撤销事件并立即清空界面，晚到图像不显示。相机关闭、环境失效、开始校准或恢复采样/试用会关闭预览。预览打开先暂停，关闭不会自动恢复。
- 进入latest、头部历史、校准与统计前移除图像字节；没有图像文件写入、录制、上传功能。OS屏幕共享或用户截图不在程序控制范围，开启提示有告知。
